

#### **1. `<b>` - Bold Text**
- **Description**: Makes text bold without implying any extra importance.
- **Example**:
  ```html
  <p>This is <b>bold</b> text.</p>
  ```


#### **2. `<strong>` - Important Text**
- **Description**: Indicates that the text is of strong importance. Browsers typically render it as bold.
- **Example**:
  ```html
  <p>This is <strong>important</strong> text.</p>
  ```



#### **3. `<i>` - Italic Text**
- **Description**: Makes text italic, often used for technical terms, phrases, or thoughts.
- **Example**:
  ```html
  <p>This is <i>italic</i> text.</p>
  ```


#### **4. `<em>` - Emphasized Text**
- **Description**: Indicates emphasis. Browsers typically render it as italic.
- **Example**:
  ```html
  <p>This is <em>emphasized</em> text.</p>
  ```


#### **5. `<mark>` - Marked/Highlighted Text**
- **Description**: Highlights text, similar to using a marker pen.
- **Example**:
  ```html
  <p>This is <mark>highlighted</mark> text.</p>
  ```


#### **6. `<small>` - Smaller Text**
- **Description**: Reduces the size of the text, often used for disclaimers or fine print.
- **Example**:
  ```html
  <p>This is <small>smaller</small> text.</p>
  ```


#### **7. `<del>` - Deleted Text**
- **Description**: Represents text that has been deleted or removed. Browsers typically render it with a strikethrough.
- **Example**: ~~deleted~~
  ```html
  <p>This is <del>deleted</del> text.</p>
  ```


#### **8. `<ins>` - Inserted Text**
- **Description**: Represents text that has been added or inserted. Browsers typically render it with an underline.
- **Example**:   
   ```html
  <p>This is <ins>inserted</ins> text.</p>
  ```


#### **9. `<sub>` - Subscript Text**
- **Description**: Displays text as subscript, often used for chemical formulas or mathematical expressions.
- **Example**:
  ```html
  <p>This is <sub>subscript</sub> text.</p>
  ```


#### **10. `<sup>` - Superscript Text**
- **Description**: Displays text as superscript, often used for footnotes or exponents.
- **Example**:
  ```html
  <p>This is <sup>superscript</sup> text.</p>
  ```
